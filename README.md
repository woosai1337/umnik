# Умник — веб-версия

Точный калькулятор с дробями, степенями и корнями, таблица умножения и игры. Работает на телефоне и компьютере, ставится как приложение (PWA).

**Сайт:** https://woosai1337.github.io/umnik/

## Что умеет

- Считает с точными дробями: 1/2 + 1/3 = 5/6, 0,1 + 0,2 = 3/10.
- Степени, кубы, корни, факториал, проценты, тригонометрия, логарифмы.
- Показывает и обыкновенную дробь, и десятичное приближение.
- Таблица умножения 6×6 … 12×12 с режимом скрытых ответов.
- Игры «Спринт 60» и «Лестница» с сериями, рекордами и конфетти.
- 9 тем, свой фото-фон, настройка размытия и прозрачности стекла.
- Клавиатура, копирование результата, история вычислений.
- PWA: можно добавить на домашний экран и открывать без браузерной обвязки.

## Горячие клавиши

- Enter или = — посчитать
- Escape — очистить
- Backspace — удалить символ
- Cmd/Ctrl + Shift + T — сменить тему
- Cmd/Ctrl + Shift + B — выбрать фото
- В играх: 1–4 — выбрать ответ

## Локальный запуск

Нужен любой статический сервер. Из папки web:

    python3 -m http.server 4173
    open http://127.0.0.1:4173/

Тесты математики:

    node --test test/math.test.mjs

## Структура

- index.html — разметка приложения
- assets/styles.css — темы и адаптивная вёрстка
- assets/app.js — логика интерфейса
- assets/math.js — парсер и точная арифметика
- test/math.test.mjs — тесты движка
- sw.js, manifest.webmanifest — PWA

## Установка на iPhone

Открыть сайт в Safari → «Поделиться» → «На экран “Домой”».
